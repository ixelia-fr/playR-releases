playR について寄せられる質問

短い回答です。答えが「いいえ」のときも、そのまま書いています。

ユニバーサルランチャーとは 料金 ストア Xbox・PlayStation・Nintendo エミュレーター サーバーと NAS データ Steam のパスワード Linux と Steam Deck コントローラーとテレビ ゲームのダウンロード 複数の PC 他との違い 対応言語

ユニバーサルゲームランチャーとは何ですか？

複数のストアで購入したゲームを 1 つのライブラリにまとめるオールインワンのソフトです。Steam、Epic、GOG と順番に開く代わりに、1 つのアプリですべてを一覧し、正しいストアでゲームを起動できます。

ゲームライブラリを 1 つにまとめる「統合ライブラリ」、大きなコレクションの整理・並べ替え・タグ付けが主目的なら「ゲームライブラリマネージャー」とも呼ばれます。

playR は無料ですか？

はい。このサイトで説明している範囲はすべて無料です。アプリ、自宅のサーバー、同期、コンソールモード。広告も定額課金もなく、当方でアカウントを作る必要もありません。必要なのはご自身のストアアカウントだけです。

今後、実際に費用がかかるサービスについては有料オプションが加わる可能性があります。たとえば外出先からライブラリにアクセスするための、当方がホストするサーバーなどです。これらはあくまで任意で、無料版の機能が削られることはありません。

playR はどのストアに対応していますか？

PC 向け 8 プラットフォーム：Steam（ファミリーライブラリを含む）、Epic Games、GOG、Amazon Games、EA、Ubisoft Connect、Battle.net、Riot Games。最後の Riot Games だけはアカウント登録が不要で、クライアントが入っていればゲームが自動的に表示されます。

さらにコンソールのライブラリが 3 つ加わります。Xbox、PlayStation Network、Nintendo です。

さらにクラウドゲーミングにも対応します。ライブラリ内で GeForce NOW や Amazon Luna で遊べるゲームは自動で判別され、インストール不要のまま playR から起動できます。

playR は Xbox、PlayStation、Nintendo のゲームも表示できますか？

はい。これは他のランチャーが標準では備えていない機能です。Xbox（コンソール版と PC 版）、PlayStation Network、Nintendo はいずれも公式のログイン画面から接続でき、そのゲームは PC ストアと同じライブラリに並びます。

注意点が 2 つあります。Nintendo はデスクトップアプリからのみ接続でき、プレイ時間は取得できません。Xbox については、取得できるのはアカウントに紐づくゲームであり、サブスクリプションで遊べる Game Pass のカタログではありません。

playR はエミュレーターや ROM、レトロゲームに対応していますか？

いいえ。これは見落としではありません。playR が扱うのは公式ストアで購入したゲームだけです。エミュレーターも ROM も、ローカルファイルのスキャンも対象外で、今後も対象にしません。

それが目的なら、LaunchBox や Playnite が非常に得意です。

どれが何をできるかは比較表で確認できます。

サーバーは必要ですか？ NAS でも動きますか？

playR はライブラリを保持する「サーバー」と、実際に開く「クライアント」の 2 つで構成されます。PC 1 台なら Windows のインストーラーが両方を同時に入れるため、設定は不要で、サーバーの存在を意識する必要もありません。

別の場所で動かしたい場合、サーバーは Docker イメージとして提供されます。Synology NAS、CasaOS、Proxmox、Unraid、TrueNAS、Portainer など。

各ケースの手順はドキュメントで説明しています。

自分のデータはどこかに送られますか？

ライブラリはあなたの端末に残ります。当方のサーバーへコピーされることはなく、接続する端末はいずれも一度コードで許可する必要があります。

playR は匿名の利用統計のみを送信します。IP アドレス、アカウント識別子、ライブラリの中身が送られることはありません。インストール時に告知し、設定画面に一覧を掲げ、スイッチ 1 つで停止できます。

パスワードを渡す必要はありますか？

いいえ。playR は各プラットフォーム公式のログイン画面、またはアクセストークンを使います。認証は各社側で行われ、playR がパスワードを保存することはありません。

Steam も同じ考え方です。Steam Guard の確認を含む公式ログインを通すことで、ファミリーライブラリにアクセスできます。希望すれば、SteamID と公開 API キーを使う方法も選べますが、その場合ファミリーライブラリは取得できません。

playR は Linux や Steam Deck、ROG Ally で動きますか？

ROG Ally など Windows 搭載の携帯機なら動きます。中身は Windows PC なので通常どおりインストールでき、コントローラー操作のコンソールモードとも相性が良い環境です。

Linux と Steam Deck では、サーバーはすでに動作します（Docker イメージのため）。ただしクライアントアプリは現状 Windows 専用です。Wine と Proton を利用した Linux 版クライアントを準備中です。それまでは Heroic Games Launcher が適任であり、その点は率直にお伝えします。

ランチャーの比較表を見る。

リビングのテレビで、コントローラーを使って遊べますか？

はい。それが TV モード、いわば本格的なコンソールモードです。大きなジャケット、カルーセル、詳細ページ、並べ替えとフィルターまで、すべてをコントローラーだけで操作でき、マウスは一切不要です。リビングのテレビでも PC のモニターでも同じように使えます。

ほかにはない要素が 2 つあります。「今夜は何を遊ぶ？」のランダム抽選と、数分放置するとスクリーンショットをスライドショー表示するスクリーンセーバーです。

playR 自体がゲームをダウンロードするのですか？

いいえ。インストールも起動も、そのゲームを所有している公式ストア経由で行われます。当方を経由するものはなく、ゲームの管理は各ストアのままです。同じゲームを複数のストアで所有している場合は、どれを使うか選べます。

同じライブラリに何台の PC を接続できますか？

台数に制限はありません。各端末は一度コードで許可すれば、同じ最新のライブラリを、評価・リスト・ステータスごと参照できます。インストールした 1 台にライブラリが留まるデスクトップ型ランチャーとの決定的な違いです。

Playnite や GOG Galaxy、Heroic との違いは何ですか？

いずれも標準では備えていない 3 点です。すべての PC で共有する自宅サーバー、ウィッシュリストの価格比較、そして無料配布の通知。一方 playR はオープンソースではなく、コミュニティ拡張もなく、レトロも扱いません。

比較表ですべてを並べて確認できます。

playR は何か国語に対応していますか？

9 言語です。フランス語、英語、ドイツ語、スペイン語、イタリア語、ポルトガル語、オランダ語、ポーランド語、ロシア語、日本語。ゲームの詳細ページも選んだ言語に追従します。
